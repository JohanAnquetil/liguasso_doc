# Publier une actualité pour vos adhérents

!!! chemin "Accès"
    Dans le menu, cliquez sur **Paramétrage**, puis sur **Actualités**.

Les actualités permettent d'informer vos adhérents : un évènement à venir, le lancement de la campagne de réadhésion, une information pratique. Elles s'affichent sur le tableau de bord des adhérents qui se connectent à Ligu'asso.

![Gestion des actualités](img/actualites.png)

## Retrouver une actualité

L'écran **Gestion des actualités - Liste** affiche les actualités déjà créées. Pour en retrouver une, utilisez le bloc **Recherche** :

- **Titre** ou **Mot clé** ;
- **A destination des** : **Adhérents** ;
- **Date de visibilité** : les actualités visibles à cette date ;
- **Top actu** : uniquement les actualités mises en avant.

Cliquez sur **Rechercher**. Les icônes de la colonne **Actions** permettent de voir, modifier ou supprimer une actualité.

## Créer une actualité

1. Cliquez sur **Ajouter une actualité**.
2. Renseignez le **Titre**, obligatoire.
3. Dans **A destination des**, choisissez **Adhérents**.
4. Indiquez si besoin les dates de **Début parution** et de **Fin parution** : en dehors de cette période, l'actualité n'est pas affichée.
5. Activez **Top actu** pour la mettre en avant.
6. Cochez la ou les fédérations concernées : **Ligue**, **Ufolep**, **Usep**.
7. Rédigez un **Libellé court**, obligatoire, puis le texte de l'actualité.
8. Dans **Documents associés**, joignez si besoin des documents depuis votre ordinateur.
9. Cliquez sur **Valider**.

L'actualité apparaît dans la liste et sur le tableau de bord de vos adhérents pendant sa période de parution.

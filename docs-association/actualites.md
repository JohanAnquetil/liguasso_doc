# Actualités

!!! chemin "Accès"
    **Paramétrage** › **Actualités**

Depuis **Paramétrage > Actualités**, vous pouvez communiquer avec vos adhérent.e.s en publiant des actualités, qui s'affichent sur leur tableau de bord.

C'est un moyen simple d'informer votre réseau : nouveaux évènements, campagne de ré-adhésion, informations diverses.

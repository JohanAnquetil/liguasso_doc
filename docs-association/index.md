## Comment se déroule une saison ?

1. Vous **renouvelez l'affiliation** de l'association pour la saison, depuis le tableau de bord.
2. Votre fédération départementale **valide l'affiliation**.
3. Vous **enregistrez vos adhérents**, un par un ou par import de fichier.
4. Vous **transmettez** ces adhésions à votre fédération, qui les **valide**.
5. En fin de saison, vous lancez votre **campagne de réadhésion** et renouvelez l'affiliation pour la saison suivante.

!!! tip "À retenir"
    Sur Ligu'asso, l'association **saisit et transmet** ; c'est la fédération départementale qui **valide**. Pour toute question sur votre affiliation, vos identifiants ou une validation, votre premier contact est votre fédération départementale.

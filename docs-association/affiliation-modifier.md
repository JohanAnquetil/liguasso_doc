# Modifier mon affiliation

!!! chemin "Accès"
    Depuis le **tableau de bord** (logo central), cliquez sur le bouton **Modifier votre affiliation**.

Vous pouvez modifier après coup les informations données lors de l'affiliation : secteur, adresse, informations générales, membres du bureau et référents. C'est aussi le seul moyen de **changer un membre du bureau** (président, trésorier, correspondant).

![Bouton Modifier votre affiliation](img/modifier-affiliation-bouton.png)

## Modifier les informations

1. Sur le tableau de bord, cliquez sur **Modifier votre affiliation**.
2. Le parcours d'affiliation s'ouvre, déjà rempli. Corrigez les étapes concernées. Le détail de chaque étape est dans [Affilier mon association](affiliation.md).
3. Allez jusqu'au résumé et cliquez sur **Valider l'affiliation**.
4. **Signez à nouveau** le bulletin d'affiliation.

![Résumé après modification](img/modifier-affiliation-resume.png)

!!! warning "Allez jusqu'au bout"
    Sans la validation **et** la nouvelle signature du bulletin, la modification **n'est pas enregistrée**. C'est la cause la plus fréquente d'une modification « perdue ».

## À savoir

- Les coordonnées de l'association (adresse, mail, téléphone) et son logo se modifient plus simplement dans [Coordonnées et logo](association-coordonnees.md).

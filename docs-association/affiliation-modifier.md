# Modifier mon affiliation

!!! chemin "Accès"
    Depuis le **tableau de bord** (logo central), cliquez sur le bouton **Modifier votre affiliation**.

Vous pouvez modifier après coup les données enregistrées lors de l'affiliation : secteur, adresse, informations générales, bureau et référents.

Depuis votre tableau de bord, cliquez sur **Modifier votre affiliation**.

![Bouton Modifier votre affiliation](img/modifier-affiliation-bouton.png)

![Résumé après modification](img/modifier-affiliation-resume.png)

!!! warning "Ne vous arrêtez pas en chemin"
    Allez jusqu'au bout du parcours : cliquez sur **Valider l'affiliation**, puis **signez à nouveau** le bulletin. Sans cette dernière étape, la modification n'est pas enregistrée.

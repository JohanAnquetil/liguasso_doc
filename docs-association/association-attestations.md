# Télécharger les attestations de l'association

!!! chemin "Accès"
    Dans le menu, cliquez sur **Mon association**, puis sur **Mes attestations**.

L'écran **Mes attestations** regroupe les attestations disponibles pour votre association et pour la saison, selon vos affiliations. Par exemple :

- **Attestation Assurance RC UFOLEP** pour la saison ;
- **Attestation RC USEP** pour la saison.

Cliquez sur une attestation pour la télécharger.

![Mes attestations](img/attestations.png)

## Bulletin et attestation depuis le tableau de bord

Le **tableau de bord** (logo central) propose aussi :

- **Visualiser votre PDF d'affiliation** : le bulletin d'affiliation de la saison ;
- **Visualiser votre affiliation** : le détail de l'affiliation dans Ligu'asso ;
- l'attestation d'assurance de votre fédération, par exemple **Attestation RC USEP**.

![Visualiser son affiliation depuis l'accueil](img/attestations-accueil.png)

## À savoir

Une attestation n'apparaît que si l'affiliation correspondante est enregistrée pour la saison. Si une attestation attendue manque, vérifiez votre affiliation ou contactez votre fédération départementale.

# Attestations

!!! chemin "Accès"
    **Mon association** › **Mes attestations**

Le sous-menu **Mes attestations** regroupe vos attestations, par exemple l'attestation RC UFOLEP.

![Mes attestations](img/attestations.png)

Vous pouvez également visualiser votre affiliation, en PDF ou directement sur Ligu'asso, depuis la page d'accueil.

![Visualiser son affiliation depuis l'accueil](img/attestations-accueil.png)

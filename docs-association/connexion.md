# Se connecter

Ligu'asso centralise la gestion de plusieurs types d'utilisateurs. Les actions possibles varient selon votre profil.

En tant que responsable d'association, vous disposez d'un espace pour gérer simplement vos adhérent.e.s.

## Récupérer ses identifiants

Votre identifiant est votre **numéro d'adhérent ou de licence**. Il vous est transmis, avec votre mot de passe, à l'adresse mail renseignée lors de votre première demande d'affiliation.

Si vous ne les connaissez pas, adressez-vous à votre **fédération départementale**.

![Formulaire de connexion](img/connexion-formulaire.png)

## Le tableau de bord

La page principale, accessible à tout moment en cliquant sur le logo central, est votre **tableau de bord**. Elle affiche l'état d'affiliation de votre association pour la saison, votre messagerie interne, vos raccourcis et votre agenda.

![Tableau de bord](img/tableau-de-bord.png)

!!! tip
    Pour accéder à l'ensemble des fonctionnalités, votre association doit être **affiliée pour la saison en cours**.

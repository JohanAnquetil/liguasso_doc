# Gérer les sections et les écoles

!!! chemin "Accès"
    - Sections : dans le menu, cliquez sur **Mon association**, puis sur **Gérer mes sections**.
    - Écoles (associations scolaires) : dans le menu, cliquez sur **Mon association**, puis sur **Gérer mes écoles**.

Une **section** regroupe les adhérents d'une même pratique, par exemple Football. Une **école** regroupe les élèves d'un même établissement, pour une association USEP. Les écoles servent notamment à importer les élèves par classe, et la fédération peut adresser une facture à une section précise.

## Créer une section ou une école

1. Dans **Gérer mes sections**, cliquez sur **+ Nouvelle Section / École**.
2. Renseignez le **Nom**, obligatoire.
3. Pour une école, ajoutez le **Code UAI** et cochez les options utiles : **Principale**, **Avec classe élémentaire**, **Avec classe maternelle**.
4. Dans **Correspondant de la section**, cliquez sur **Sélectionnez un correspondant** si vous voulez désigner un responsable (facultatif).
5. Cliquez sur **Valider**.

## Consulter les écoles d'une saison

Dans **Gérer mes écoles**, choisissez la **Saison**, vérifiez l'**Association**, puis cliquez sur **Afficher** : les écoles de la saison s'affichent dans **Résultats**.

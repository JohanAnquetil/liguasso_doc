# Sections et écoles

Dans le sous-menu **Gérer mes sections / écoles**, vous pouvez créer des sections par type de pratique (par exemple Football) ou par école. Cliquez sur **+ Nouvelle Section / École**.

![Bouton Nouvelle Section / École](img/sections-bouton.png)

Ajoutez le nom de la section ou de l'école (**obligatoire**), attribuez un correspondant (facultatif) et, selon les cas, le code UAI ainsi que les options Principale, classe élémentaire ou classe maternelle — dans le contexte d'une activité scolaire.

![Saisie d'une section ou d'une école](img/sections-saisie.png)

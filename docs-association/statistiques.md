# Extraire la liste de ses adhérents

!!! chemin "Accès"
    Dans le menu, cliquez sur **Statistiques et Extractions**, puis sur **Extractions**, puis sur **Extraction adhérents**.

L'écran **Extraction adhérents** produit un fichier Excel de vos adhérents, filtrés selon les critères saisis lors de leur adhésion. Le fichier contient leur état civil et leurs données d'adhésion : date de validation ou d'homologation, activités pratiquées.

![Extraction adhérents](img/extractions.png)

## Extraire les adhérents

1. Dans le bloc **Paramètres**, choisissez la **Saison** (obligatoire). Le **Département** et l'**Association** sont déjà remplis.
2. Affinez si besoin avec les filtres (tous facultatifs) :
    - **Activité / Dispositif fédéral** ;
    - **Catégorie d'adhérent** : **Adhérents Socioculturels**, **Licenciés Usep**, **Licenciés Ufolep**, **Adhérents Ufopass** ;
    - **Etat adhésion** : **A réadhérer**, **En cours**, **Validée**, **Refusée**, **Rejetée** ;
    - **Sexe** et **Tranche d'âge** ;
    - les interrupteurs **Loisirs**, **Compétitions**, **Officiels**, **Animateurs**, **Dirigeants**, pour ne garder que les adhérents concernés ;
    - pour l'USEP : **Ecole** (maternelle ou élémentaire), **Cycle** et **Niveau**.
3. Choisissez le **Type de sortie** : **Sortie simple Ligue**, **Sortie simple Ufolep**, **Sortie complète Ufolep**, **Sortie simple Usep** ou **Sortie complète Usep**. Les sorties simples donnent une liste courte ; les sorties complètes reprennent toutes les informations de l'adhésion.
4. Cliquez sur **Extraire les données**. Le bouton **Télécharger** permet de récupérer le fichier Excel.

## À savoir

Selon le type d'affiliation de votre association, certains filtres ou types de sortie peuvent ne pas vous concerner.

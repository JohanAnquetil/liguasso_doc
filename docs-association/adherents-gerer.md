# Rechercher et gérer les adhésions

!!! chemin "Accès"
    Dans le menu, cliquez sur **Adhésion**, puis sur **Gérer les adhésions**.

L'écran **Gérer les adhésions** regroupe les adhésions de votre association enregistrées une par une. Vous pouvez y créer une adhésion, consulter un dossier, le modifier, le renouveler, imprimer une licence et suivre la validation par votre fédération.

![Menu Adhésion](img/adhesion-menu.png)

## Rechercher un adhérent

1. Dans le bloc **Recherche d'adhésions**, renseignez un ou plusieurs critères : **N° de l'adhérent**, **Nom**, **Prénom**.
2. Affinez si besoin avec la **Saison** et l'**État** du dossier.
3. Cliquez sur **Rechercher**. **Vider** efface les critères ; **Recherche Avancée** propose des filtres supplémentaires.

![Formulaire de recherche](img/gerer-recherche.png)

## Agir sur une adhésion

Les résultats s'affichent sous le formulaire. Les icônes de la colonne **Actions** permettent de **voir le détail**, **modifier**, **renouveler** l'adhésion pour la nouvelle saison et **imprimer** la licence.

![Résultat de recherche](img/gerer-resultats.png)

## Les états d'une adhésion

Le filtre **État** propose les valeurs suivantes : **à réadhérer**, **en attente adh.**, **dossier à traiter**, **en cours**, **validée**, **refusée**, **rejetée**, **dévalidée**, **suspendue**. Les plus courantes :

- **à réadhérer** : adhérent de la saison précédente, pas encore renouvelé ;
- **en attente adh.** : adhésion transmise, en attente de validation par la fédération ;
- **validée** : adhésion validée par la fédération ; la licence est disponible.

## À savoir

- Les adhésions **importées par fichier** ne s'affichent pas ici : elles sont dans [Lots](adherents-lots.md).
- Une adhésion n'est définitive qu'une fois **validée par votre fédération départementale**.

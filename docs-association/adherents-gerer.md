# Rechercher et gérer

!!! chemin "Accès"
    Dans le menu, cliquez sur **Adhésion**, puis sur **Gérer les adhésions**.

Le menu **Adhésion** vous permet de gérer vos adhérent.e.s. Vous pouvez y créer de nouvelles adhésions, les consulter, les modifier et les transmettre à votre fédération pour validation. Vous pouvez également importer des adhésions en nombre, suivre vos lots et organiser vos campagnes de ré-adhésion.

![Menu Adhésion](img/adhesion-menu.png)

## Rechercher un.e adhérent.e

Dans **Gérer les adhésions**, recherchez par numéro d'adhérent, nom ou prénom. Vous pouvez filtrer par saison ou par état d'avancement du dossier.

![Formulaire de recherche](img/gerer-recherche.png)

Les résultats s'affichent sous le formulaire. Les icônes de la colonne **Actions** permettent de voir les détails, modifier, renouveler et imprimer.

![Résultat de recherche](img/gerer-resultats.png)

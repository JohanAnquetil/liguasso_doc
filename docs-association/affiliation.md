# Affilier mon association

!!! chemin "Accès"
    Depuis le **tableau de bord** (logo central), cliquez sur le bouton **Renouveler son affiliation**, affiché pendant la campagne de réaffiliation.

Si vous êtes membre du bureau et habilité.e — président.e, trésorier.ère, correspondant.e ou gestionnaire web — vous pouvez réaffilier votre association pour la saison à venir.

!!! note "Première affiliation"
    En cas de première affiliation, contactez votre fédération départementale pour un premier enregistrement dans Ligu'asso.

Depuis votre tableau de bord, cliquez sur **Renouveler son affiliation**.

![Bouton Renouveler son affiliation](img/affiliation-renouveler.png)

## Le parcours commun

Suivez le parcours et, à chaque étape, vérifiez les informations et effectuez les modifications nécessaires.

!!! warning "Champs obligatoires"
    Les informations marquées d'un astérisque **\*** doivent être remplies pour passer à l'étape suivante.

### Affiliation

Indiquez la saison, la date d'affiliation, le ou les types d'affiliation et le type d'association.

![Étape Affiliation](img/affiliation-etape-affiliation.png)

### Association

Vérifiez les coordonnées du siège, les informations légales (date de déclaration, SIRET, RNA, objet social) et les éléments de communication.

![Étape Association](img/affiliation-etape-association.png)

### Informations générales

Renseignez les effectifs, les documents, les zones d'intervention et les thématiques. Certains champs n'apparaissent qu'en fonction du type d'affiliation sélectionné.

![Étape Informations générales](img/affiliation-infos-generales.png)

### Bureau et référents

Trois membres sont obligatoires : le/la **président.e**, le/la **trésorier.ère** et le/la **correspondant.e**. Vous pouvez aussi indiquer une adresse mail pour la réception des factures.

![Étape Bureau et référents](img/affiliation-bureau.png)

![Ajout d'un membre du bureau](img/affiliation-ajout-membre.png)

!!! tip "Doublons"
    Si la personne existe déjà dans la base en tant qu'adhérent.e, une fenêtre propose de lier l'ajout au profil existant.

## Les étapes propres à chaque fédération

=== "Ligue (socioculturel)"

    Sélectionnez au moins une activité de type socioculturel. Les activités sélectionnées seront les seules à pouvoir être indiquées sur le profil de vos adhérent.e.s.

    ![Activités socioculturelles](img/affiliation-socioculturelle.png)

    Si votre affiliation est **uniquement socioculturelle**, passez directement au [résumé](affiliation-valider.md).

=== "UFOLEP"

    **Type d'affiliation.** L'UFOLEP en propose trois, selon l'effectif de licencié.e.s et les actions de l'association :

    - **de base** : tous les adhérent.e.s de l'association, ou d'une section dédiée, sont licencié.e.s UFOLEP ;
    - **plus** : l'association peut accueillir jusqu'à 300 personnes non licenciées sur la saison ;
    - **pro** : l'association peut accueillir plus de 300 personnes non licenciées sur la saison.

    Indiquez ensuite si l'association conserve les documents de licence ou les transmet à la fédération, et si elle a signé une convention UFOPASS ou TIPO.

    ![Type d'affiliation UFOLEP](img/ufolep-type-affiliation.png)

    **Activités.** Sélectionnez-les dans le menu déroulant ou par recherche alphabétique, puis cliquez sur **+**. Pour chaque activité, définissez le ou les types de licence délivrés.

    ![Sélection des activités](img/ufolep-activites.png)

    ![Recherche alphabétique](img/ufolep-activites-liste.png)

    **Dispositifs fédéraux.** En cas de convention UFOPASS, indiquez le dispositif concerné.

    ![Dispositifs fédéraux](img/ufolep-dispositifs.png)

    **Options.** Complétez si l'association est concernée : école de conduite moto, association sportive employeuse, marrainage, Pass'Sport. Les informations d'assurance sont rappelées ici.

    ![Options UFOLEP](img/ufolep-options.png)

=== "USEP"

    **Caractéristique de l'association.** Selon votre choix, renseignez les informations sur la ou les écoles — le **code UAI est obligatoire** — puis cliquez sur **+**.

    ![Caractéristique de l'association](img/usep-caracteristiques.png)

    !!! tip
        Pour permettre la souscription au contrat d'établissement, renseignez les informations de chaque école rattachée.

    **Comité directeur.** Renseignez sa composition. Selon les statuts de l'USEP, il comprend pour une part des enfants scolarisés.

    ![Comité directeur](img/usep-comite.png)

    **Assurance.** Indiquez les effectifs de l'établissement, le nombre d'élèves licenciés et le choix de souscription au contrat d'établissement.

    ![Assurance — contrat d'établissement](img/usep-assurance.png)

    Une attestation pré-complétée peut être générée si un contrat est souscrit.

    ![Attestation](img/usep-attestation.png)

    !!! note
        La gestion des classes et des écoles s'effectue une fois l'affiliation enregistrée, dans [Mon association](association-sections.md).

# Consulter ses factures et ses règlements

!!! chemin "Accès"
    Dans le menu, cliquez sur **Comptabilité**, puis sur **Mon compte**.

L'écran **Mon compte** regroupe toutes les pièces comptables de votre association : factures émises par la fédération et règlements enregistrés. C'est le moyen le plus simple de savoir **si vous êtes à jour de vos paiements**.

![Mon compte](img/comptabilite.png)

## Lire le tableau

Chaque ligne est une pièce comptable :

- **Factures** et **Règlements** : le numéro de la pièce ;
- **Date** ;
- **Débit** : ce que l'association doit (une facture) ;
- **Crédit** : ce que l'association a payé (un règlement) ;
- **Lettrage** : une même lettre relie une facture aux règlements qui l'ont soldée. Une facture sans lettrage n'est pas encore entièrement réglée.

## Un règlement n'apparaît pas ?

Un règlement n'apparaît qu'une fois **enregistré par votre fédération départementale**. Si vous avez payé récemment, il n'est peut-être pas encore saisi. Contactez votre fédération avant de payer une deuxième fois.

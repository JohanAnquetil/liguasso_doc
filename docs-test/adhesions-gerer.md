# Rechercher et gérer les adhésions

!!! chemin "Accès"
    Dans le menu, cliquez sur **Adhésion**, puis sur **Gérer les adhésions**.

L'écran **Gérer les adhésions** regroupe les adhésions enregistrées une par une dans toutes les associations de votre département. Vous pouvez y consulter un dossier, le modifier, le valider, renouveler une adhésion ou imprimer une licence.

![Menu Adhésion](img/dep-adhesion-menu.png)

## Rechercher un adhérent

1. Dans le bloc **Recherche d'adhésions**, renseignez un ou plusieurs critères : **N° de l'adhérent**, **Nom**, **Prénom**.
2. Affinez si besoin avec la **Saison**, l'**Association** et l'**État** du dossier.
3. Cliquez sur **Rechercher**. **Vider** efface les critères ; **Recherche Avancée** ajoute des filtres.

![Gérer les adhésions](img/dep-adhesions-gerer.png)

Les icônes de la colonne **Actions** permettent de voir le détail, modifier, renouveler et imprimer.

![Résultat de recherche](img/dep-adhesions-resultat.png)

## Retrouver les adhésions à valider

1. Dans **Recherche d'adhésions**, choisissez la **Saison** et, si besoin, l'**Association**.
2. Dans **État**, sélectionnez **en attente adh.**
3. Cliquez sur **Rechercher**.

![Recherche des adhésions en attente](img/dep-attente-recherche.png)

Pour valider de nombreuses adhésions d'un coup, utilisez plutôt la [validation en masse](adhesions-valider.md).

## Les états d'une adhésion

Le filtre **État** propose : **à réadhérer**, **en attente adh.**, **en attente asso.**, **dossier à traiter**, **validée**, **refusée**, **rejetée**, **dévalidée**, **suspendue**. Les plus utilisés :

- **à réadhérer** : adhérent de la saison précédente, pas encore renouvelé ;
- **en attente adh.** : adhésion transmise par l'association, à valider par la fédération ;
- **validée** : adhésion validée ; la licence est disponible.

## À savoir

Les adhésions **importées par fichier** ne s'affichent pas ici : elles sont dans [Lots](adhesions-lots.md).

# Créer et gérer les produits facturés

!!! chemin "Accès"
    Dans le menu, cliquez sur **Paramétrage**, puis sur **Facturation**, puis sur **Gestion des produits**.

Les **produits** sont les lignes que vous facturez aux associations : affiliations, adhésions, cotisations, prestations diverses. Un produit doit exister ici pour pouvoir être ajouté à une facture.

## Retrouver un produit

1. Sur l'écran **Gestion des produits - Liste**, renseignez un ou plusieurs critères : **Code Produit**, **Libellé Produit**, **Structure** (LIGUE, UFOLEP, USEP), **Saison**, **Famille de tarif** (**AFFI - Affiliation**, **ADH - Adhésion**, **AUTRE - Autres produits**).
2. Cliquez sur **Rechercher**.

![Gestion des produits](img/dep-produits-liste.png)

!!! tip "Votre produit n'apparaît pas ?"
    Décochez les options **Mes produits** et **Produits calculés**, puis relancez la recherche.

## Créer un produit

1. Cliquez sur **Ajouter un produit**, en haut à droite.

    ![Ajouter un produit](img/dep-produits-ajouter.png)

2. **Bloc Produit** : renseignez le **Code Produit**, le **Libellé Produit**, la **Structure** et la **Saison** (tous obligatoires). Le libellé est celui qui apparaît sur la facture : choisissez-le clair pour l'association.
3. **Bloc Tarifs** : choisissez le niveau du tarif (**National**, **Départemental** ou **Assurantiel**) et la **Famille de tarif** (obligatoire). Le **Type de tarif** (**FORFAIT**, **TRANCHE**, **UNITAIRE**) et la **Tranche d'âge** sont facultatifs.
4. **Bloc Produits associés** (facultatif) : sélectionnez un produit dans la liste, puis cliquez sur **+** pour l'ajouter. Le **Total Produit** se calcule automatiquement.
5. Cliquez sur **Valider**.

![Création d'un produit](img/dep-produits-creation.png)

!!! warning "Choisir la bonne famille de tarif"
    Pour qu'un produit que vous créez apparaisse dans vos factures, choisissez la famille **AUTRE - Autres produits**.

Le produit est ensuite disponible dans [Facturation et règlements](facturation.md). Pensez à lui associer ses comptes dans le [plan comptable des produits](parametrage-plans-comptables.md).

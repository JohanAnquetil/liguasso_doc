# Créer une affiliation

!!! chemin "Accès"
    **Affiliation** › **Gérer les affiliations**, puis bouton **Nouvelle affiliation**

## Le parcours commun

!!! warning "Champs obligatoires"
    Les informations marquées d'un astérisque **\*** doivent être remplies pour passer à l'étape suivante.

### Affiliation

Renseignez les informations demandées dans la rubrique **Affiliation**, puis sélectionnez le ou les types d'affiliation.

![Étape Affiliation](img/dep-affiliation-etape1.png)

### Association

Entrez les coordonnées et les informations légales de l'association. La **date de déclaration au Tribunal** et l'**objet social** sont obligatoires.

![Étape Association](img/dep-affiliation-association.png)

!!! note "RNA et SIRET"
    Le n° RNA et le n° de SIRET ne sont pas obligatoires dans Ligu'asso. Nous recommandons vivement de les récupérer auprès de l'association, afin de respecter la réglementation en vigueur.

### Informations générales

Renseignez les effectifs globaux, le champ d'intervention, et ajoutez des documents si besoin. Si l'association est employeuse, activez **L'association est employeur** et renseignez le nombre d'ETP.

Pour ajouter un document au format PDF : **Parcourir** → sélectionnez le fichier → choisissez un type de document → **Ajouter**.

![Étape Informations générales](img/dep-affiliation-infos.png)

!!! note "Stockage des documents"
    Dans un souci de respect des données personnelles, les documents ne peuvent pas être stockés sur Ligu'asso pour le moment. Conservez-les sur votre poste.

### Bureau et référents

Trois membres sont obligatoires : le/la **président.e**, le/la **trésorier.ère** et le/la **correspondant.e**. D'autres rôles existent — gestionnaire web, secrétaire, co-président.e — sans obligation.

Dans le menu déroulant, sélectionnez le rôle puis cliquez sur **Ajouter**.

![Ajouter un membre](img/dep-affiliation-bureau-ajouter.png)

Une fenêtre s'ouvre. Le nom, le prénom, la date de naissance et l'**email** sont obligatoires.

![Fenêtre d'ajout](img/dep-affiliation-bureau-fenetre.png)

![Bureau complété](img/dep-affiliation-bureau.png)

!!! tip "Correspondant.e"
    Assurez-vous que les coordonnées du correspondant sont bien celles de la personne qui recevra les factures, pour éviter toute erreur d'envoi.

## Les étapes propres à chaque fédération

=== "Ligue (socioculturel)"

    Sélectionnez le bouton **Socio-culturelle** au début du parcours.

    ![Choix socioculturel](img/dep-affiliation-socio.png)

    Cochez ensuite les activités correspondant à celles de l'association, puis passez à l'étape suivante.

    ![Activités socioculturelles](img/dep-affiliation-activites-socio.png)

=== "UFOLEP"

    Sélectionnez le bouton **UFOLEP** au début du parcours.

    ![Choix UFOLEP](img/dep-ufolep-choix.png)

    Dans l'onglet **UFOLEP**, sélectionnez le type d'affiliation correspondant à l'activité de l'association. Il dépend de l'effectif de licencié.e.s UFOLEP.

    ![Types d'affiliation UFOLEP](img/dep-ufolep-types.png)

    Indiquez si l'association a une convention UFOPASS ou TIPO avec la fédération.

    ![Conventions](img/dep-ufolep-conventions.png)

    Plus bas, sélectionnez les dispositifs fédéraux en cas de convention UFOPASS.

    ![Dispositifs fédéraux](img/dep-ufolep-dispositifs.png)

    Sélectionnez enfin les activités que l'association déclare organiser.

    ![Activités sportives](img/dep-ufolep-activites.png)

=== "USEP"

    Sélectionnez le bouton **USEP** au début du parcours.

    ![Choix USEP](img/dep-usep-choix.png)

    Dans l'onglet **USEP**, sélectionnez le type d'association, puis indiquez le nom de l'école, son code UAI et ses classes.

    ![Caractéristique de l'association](img/dep-usep-caracteristiques.png)

    Renseignez ensuite la composition du comité directeur.

    ![Comité directeur](img/dep-usep-comite.png)

    L'onglet **Assurance** apparaît : indiquez les effectifs de l'établissement, les licenciés élèves et le choix de souscription au contrat d'établissement.

    ![Assurance](img/dep-usep-assurance.png)

## Valider l'affiliation

Le **résumé** récapitule l'ensemble des données saisies et permet de récupérer le bulletin d'affiliation.

![Résumé](img/dep-affiliation-resume.png)

Si tout est correct, cliquez sur **Valider l'affiliation**. Une fenêtre s'ouvre : vous pouvez y modifier la date d'affiliation et déposer le document signé si vous en disposez. Sinon, cliquez directement sur **Valider**.

![Fenêtre de validation](img/dep-affiliation-valider-popup.png)

L'affiliation apparaît alors dans **Gérer les affiliations**, avec son statut et ses actions : visualiser, modifier, imprimer le bulletin, consulter l'historique.

![Retour à la liste](img/dep-affiliation-liste.png)

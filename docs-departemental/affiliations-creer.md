# Créer une affiliation

!!! chemin "Accès"
    Dans le menu, cliquez sur **Affiliation**, puis sur **Gérer les affiliations**, puis sur le bouton **Nouvelle affiliation**.

Cette fiche décrit l'enregistrement d'une **nouvelle** association dans Ligu'asso. Pour une association déjà affiliée la saison précédente, utilisez plutôt [Réaffilier une association](reaffiliation-association.md) : le parcours est alors déjà rempli.

!!! warning "Champs obligatoires"
    Les champs marqués d'un astérisque **\*** doivent être remplis pour passer à l'étape suivante.

## Étape Affiliation

Renseignez les informations de la rubrique **Affiliation**, puis sélectionnez le ou les types d'affiliation : **Socio-culturelle**, **UFOLEP**, **USEP**. Ce choix détermine les étapes propres à chaque fédération (voir plus bas).

![Étape Affiliation](img/dep-affiliation-etape1.png)

## Étape Association

Saisissez les coordonnées et les informations légales de l'association. La **date de déclaration au Tribunal** et l'**objet social** sont obligatoires.

![Étape Association](img/dep-affiliation-association.png)

!!! note "RNA et SIRET"
    Les numéros RNA et SIRET ne sont pas obligatoires dans Ligu'asso. Demandez-les quand même à l'association : ils sont nécessaires pour respecter la réglementation.

## Étape Informations générales

Renseignez les effectifs globaux et le champ d'intervention. Si l'association emploie des salariés, activez **L'association est employeur** et indiquez le nombre d'ETP (équivalents temps plein).

Pour ajouter un document PDF : cliquez sur **Parcourir**, sélectionnez le fichier, choisissez le type de document, puis cliquez sur **Ajouter**.

![Étape Informations générales](img/dep-affiliation-infos.png)

!!! note "Stockage des documents"
    Pour protéger les données personnelles, les documents ne peuvent pas être conservés sur Ligu'asso pour le moment. Gardez-en une copie sur votre ordinateur.

## Étape Bureau et référents

Trois membres sont obligatoires : le **président**, le **trésorier** et le **correspondant**. D'autres rôles sont possibles, sans obligation : gestionnaire web, secrétaire, coprésident.

1. Dans la liste déroulante, choisissez le rôle, puis cliquez sur **Ajouter**.
2. Dans la fenêtre qui s'ouvre, renseignez le **nom**, le **prénom**, la **date de naissance** et l'**email** (obligatoires), puis validez.
3. Recommencez pour chaque membre.

![Ajouter un membre](img/dep-affiliation-bureau-ajouter.png)

![Fenêtre d'ajout](img/dep-affiliation-bureau-fenetre.png)

![Bureau complété](img/dep-affiliation-bureau.png)

!!! tip "Le correspondant reçoit les factures"
    Vérifiez que les coordonnées du correspondant sont celles de la personne qui doit recevoir les factures, pour éviter les erreurs d'envoi.

## Les étapes propres à chaque fédération

=== "Ligue (socioculturel)"

    1. Au début du parcours, sélectionnez **Socio-culturelle**.

        ![Choix socioculturel](img/dep-affiliation-socio.png)

    2. Cochez les activités de l'association, puis passez à l'étape suivante. Seules ces activités pourront être indiquées sur les adhésions de l'association.

        ![Activités socioculturelles](img/dep-affiliation-activites-socio.png)

=== "UFOLEP"

    1. Au début du parcours, sélectionnez **UFOLEP**.

        ![Choix UFOLEP](img/dep-ufolep-choix.png)

    2. Dans l'onglet **UFOLEP**, choisissez le **type d'affiliation**. Il dépend de l'effectif de licenciés UFOLEP : **de base** (tous les adhérents sont licenciés), **plus** (jusqu'à 300 personnes non licenciées accueillies sur la saison) ou **pro** (plus de 300).

        ![Types d'affiliation UFOLEP](img/dep-ufolep-types.png)

    3. Indiquez si l'association a une convention **UFOPASS** ou **TIPO** avec la fédération.

        ![Conventions](img/dep-ufolep-conventions.png)

    4. En cas de convention UFOPASS, sélectionnez plus bas les **dispositifs fédéraux** concernés.

        ![Dispositifs fédéraux](img/dep-ufolep-dispositifs.png)

    5. Sélectionnez les activités que l'association organise.

        ![Activités sportives](img/dep-ufolep-activites.png)

=== "USEP"

    1. Au début du parcours, sélectionnez **USEP**.

        ![Choix USEP](img/dep-usep-choix.png)

    2. Dans l'onglet **USEP**, choisissez le type d'association, puis indiquez le nom de l'école, son **code UAI** et ses classes.

        ![Caractéristique de l'association](img/dep-usep-caracteristiques.png)

    3. Renseignez la composition du **comité directeur**.

        ![Comité directeur](img/dep-usep-comite.png)

    4. Dans l'onglet **Assurance**, indiquez les effectifs de l'établissement, le nombre d'élèves licenciés et le choix de souscrire ou non au contrat d'établissement.

        ![Assurance](img/dep-usep-assurance.png)

## Valider l'affiliation

1. Le **résumé** récapitule toutes les informations. Il permet aussi de télécharger le bulletin d'affiliation.

    ![Résumé](img/dep-affiliation-resume.png)

2. Si tout est correct, cliquez sur **Valider l'affiliation**.
3. Dans la fenêtre qui s'ouvre, modifiez si besoin la **date d'affiliation** et déposez le bulletin signé si vous l'avez. Sinon, cliquez directement sur **Valider**.

    ![Fenêtre de validation](img/dep-affiliation-valider-popup.png)

L'affiliation apparaît dans **Gérer les affiliations**, avec son état et ses actions : visualiser, modifier, imprimer le bulletin, consulter l'historique.

![Retour à la liste](img/dep-affiliation-liste.png)

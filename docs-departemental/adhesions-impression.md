# Imprimer les cartes et les licences

!!! chemin "Accès"
    Dans le menu, cliquez sur **Adhésion**, puis sur **Impression des cartes et licences**.

Cet écran permet de retrouver les adhésions validées et d'imprimer les cartes d'adhérent et les licences correspondantes.

![Menu Impression](img/dep-impression-menu.png)

## Rechercher les licences à imprimer

1. Dans le bloc **Recherche d'adhésions**, choisissez la **Saison** et, si besoin, l'**Association**. Vous pouvez aussi chercher une personne par **N° de l'adhérent**, **Nom** ou **Prénom**.
2. Laissez l'**État** sur **validée** : seules les adhésions validées ont une licence.
3. Renseignez la période de validation avec **Date de validation du** et **Date de validation au**.
4. Cochez **Inclure les cartes/licences déjà imprimées** si vous voulez aussi les retrouver.
5. Dans **Impression des cartes/licences**, cochez qui doit imprimer : **Par la fédération**, **Par l'association**, **Par l'adhérent**.
6. Cliquez sur **Rechercher**.

![Recherche pour impression](img/dep-impression-recherche.png)

!!! warning "Deux réglages expliquent la plupart des licences « manquantes »"
    - **La période de validation** doit couvrir les dates de validation des adhésions recherchées : une période trop courte fait disparaître des licences de la liste.
    - **Inclure les cartes/licences déjà imprimées** doit être coché pour retrouver une licence déjà imprimée. Sinon, elle n'apparaît pas, ce qui donne l'impression d'un dysfonctionnement.

## Imprimer

Dans **Résultats**, cochez les licences à imprimer. Pour tout sélectionner, cochez la case située à côté de l'en-tête **Association**. Lancez ensuite l'impression.

!!! warning "Limitation connue — septembre 2026"
    L'envoi des cartes et licences par mail depuis Ligu'asso peut échouer. En attendant la correction, enregistrez-les sur votre ordinateur et envoyez-les depuis votre propre messagerie.

# Champs supplémentaires

!!! chemin "Accès"
    **Paramétrage** › **Champs supplémentaires**

Cette page permet à votre fédération d'ajouter ses **propres champs** aux formulaires de Ligu'asso, pour recueillir des informations qui n'existent pas par défaut.

![Menu Champs supplémentaires](img/dep-champs-menu.png)

## Rechercher un champ

Filtrez par code, libellé, application ou type, puis cliquez sur **Rechercher** pour afficher la liste des champs existants. Vous pouvez y modifier un champ déjà enregistré.

## Ajouter un champ

Cliquez sur **+ Ajouter un champ**, puis renseignez :

- un **code** et un **libellé** — le libellé est ce que verra l'utilisateur ;
- l'**application**, c'est-à-dire le formulaire où le champ apparaîtra : affiliation ou adhésion ;
- le **type de champ** : texte, date, liste, case à cocher, liste déroulante.

Le **département** est rempli automatiquement avec celui de votre fédération. Activez **Obligatoire** si le champ doit être rempli pour valider le formulaire, puis cliquez sur **Valider**.

!!! example "Par exemple"
    Ci-dessous, trois champs ont été ajoutés aux associations affiliées : *Diffusion*, *Secteur USEP pour rencontres sportives* et un champ *test*. Le champ **Diffusion** sert ensuite de filtre dans les [extractions](statistiques.md).

# Ajouter des champs supplémentaires aux formulaires

!!! chemin "Accès"
    Dans le menu, cliquez sur **Paramétrage**, puis sur **Champs supplémentaires**.

Votre fédération peut ajouter ses **propres champs** aux formulaires d'affiliation ou d'adhésion, pour recueillir des informations que Ligu'asso ne demande pas par défaut. Ces champs peuvent ensuite servir de filtres dans les [extractions](statistiques.md).

![Menu Champs supplémentaires](img/dep-champs-menu.png)

## Retrouver un champ

Sur l'écran **Gestion des champs de saisie supplémentaires - Liste**, filtrez par **Code**, **Libellé**, **Application** ou **Type**, puis cliquez sur **Rechercher**. Vous pouvez ensuite modifier un champ existant.

## Ajouter un champ

1. Cliquez sur **Ajouter un champ**.
2. Renseignez un **Code** (identifiant court) et un **Libellé** : le libellé est le texte que verra l'utilisateur.
3. Choisissez l'**Application**, c'est-à-dire le formulaire où le champ apparaîtra : **Affiliation** ou **Adhésion**.
4. Choisissez le **Type** de champ : **Case à cocher**, **Champ libre**, **Date**, **Entier**, **Liste déroulante** ou **Liste à sélection multiple**.
5. Le **Département** est rempli avec celui de votre fédération.
6. Cochez **Obligatoire** si le champ doit être rempli pour valider le formulaire.
7. Cliquez sur **Valider**.

## Exemple

Une fédération a ajouté au formulaire d'affiliation trois champs : **Diffusion**, **Secteur USEP pour rencontres sportives** et un champ d'essai **test**. Ils apparaissent dans une rubrique complémentaire du formulaire, et le champ **Diffusion** sert de filtre dans les extractions d'adhérents et d'associations.

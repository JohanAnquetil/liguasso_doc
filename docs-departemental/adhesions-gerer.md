# Rechercher et gérer les adhésions

!!! chemin "Accès"
    **Adhésion** › **Gérer les adhésions**

Le menu **Adhésion** regroupe la gestion des adhérent.e.s de toutes vos associations : créer une adhésion, consulter un dossier, le modifier, renouveler ou imprimer une licence.

![Menu Adhésion](img/dep-adhesion-menu.png)

## Rechercher un.e adhérent.e

Recherchez par numéro d'adhérent, nom ou prénom. Vous pouvez filtrer par saison, par association ou par état d'avancement du dossier.

![Gérer les adhésions](img/dep-adhesions-gerer.png)

Les icônes de la colonne **Actions** permettent de voir les détails, modifier, renouveler et imprimer.

![Résultat de recherche](img/dep-adhesions-resultat.png)

## Retrouver une adhésion en attente

1. Survolez **Adhésion** puis cliquez sur **Gérer les adhésions**.
2. Saisissez vos critères dans **Recherche d'adhésion**.
3. Ouvrez le menu **État** et sélectionnez **En attente adh.**
4. Cliquez sur **Rechercher**.

![Recherche des adhésions en attente](img/dep-attente-recherche.png)

!!! tip "Adhésion introuvable ?"
    Les adhésions issues d'un import ne se rangent pas dans **Gérer les adhésions** mais dans [Lots](adhesions-lots.md).

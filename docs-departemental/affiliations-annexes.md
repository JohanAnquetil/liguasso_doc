# Documents, sections et écoles

!!! chemin "Accès"
    - Documents d'affiliation : **Affiliation** › **Documents d'affiliation**
    - Sections : **Affiliation** › **Gérer les sections**
    - Écoles : **Affiliation** › **Gérer les écoles**

## Documents d'affiliation

Le sous-menu **Documents d'affiliation** regroupe les documents liés aux affiliations de votre fédération.

![Menu Documents d'affiliation](img/dep-documents-menu.png)

## Sections et écoles

Dans **Affiliation > Gérer les sections** (ou **Gérer les écoles**), vous pouvez ajouter des sections par type de pratique (par exemple Football) ou par école.

![Menu Gérer les sections](img/dep-sections-menu.png)

Recherchez d'abord l'association concernée, puis cliquez sur **+ Nouvelle Section / École**, en haut à droite.

![Page Gérer les sections](img/dep-sections-page.png)

Ajoutez le nom de la section ou de l'école (**obligatoire**), attribuez un correspondant (facultatif) et, selon les cas, le code UAI ainsi que les options Principale, classe élémentaire ou maternelle — dans le contexte d'une activité scolaire.

![Saisie d'une section](img/dep-sections-saisie.png)

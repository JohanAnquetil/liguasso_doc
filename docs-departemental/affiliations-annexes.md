# Documents d'affiliation, sections et écoles

!!! chemin "Accès"
    - Documents d'affiliation : dans le menu, cliquez sur **Affiliation**, puis sur **Documents d'affiliation**.
    - Sections : dans le menu, cliquez sur **Affiliation**, puis sur **Gérer les sections**.
    - Écoles : dans le menu, cliquez sur **Affiliation**, puis sur **Gérer les écoles**.

## Consulter les documents d'affiliation

L'écran **Documents d'affiliation pour la saison en cours** regroupe les documents liés aux affiliations de votre fédération pour la saison. S'il n'y en a pas, le message **Aucun document n'a été trouvé pour cette saison** s'affiche.

![Menu Documents d'affiliation](img/dep-documents-menu.png)

## Créer une section ou une école pour une association

Une **section** regroupe les adhérents d'une même pratique (par exemple Football) ; une **école** regroupe les élèves d'un établissement, pour une association USEP.

1. Dans **Gérer les sections**, recherchez l'association concernée.
2. Cliquez sur **+ Nouvelle Section / École**, en haut à droite.
3. Renseignez le **Nom** (obligatoire).
4. Pour une école, ajoutez le **Code UAI** et cochez les options utiles : **Principale**, **Avec classe élémentaire**, **Avec classe maternelle**.
5. Si besoin, désignez un correspondant avec **Sélectionnez un correspondant** (facultatif).
6. Cliquez sur **Valider**.

## Consulter les écoles d'une association

Dans **Gérer les écoles**, choisissez la **Saison** et l'**Association**, puis cliquez sur **Afficher**.

## À savoir

Les classes et les écoles doivent être à jour **avant** d'importer des élèves USEP, car l'import se fait classe par classe. → [Importer un fichier d'adhésions](adhesions-import.md)

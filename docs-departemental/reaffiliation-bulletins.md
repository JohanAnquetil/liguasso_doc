# Bulletins de ré-adhésion

!!! chemin "Accès"
    **Affiliation** › **Gestion des bulletins de ré-adhésion**

Cet écran permet de demander la génération de la liasse des bulletins de ré-adhésion d'une association. La liasse est produite par la plateforme, puis mise à votre disposition par mail.

![Menu Gestion des bulletins](img/dep-bulletins-menu.png)

1. Dans le bloc **Recherche**, saisissez le nom de l'association dans le champ **Association**, sélectionnez-la, puis cliquez sur **Rechercher**.

    ![Page des bulletins](img/dep-bulletins-page.png)

2. Dans la colonne **Actions**, cliquez sur l'icône **Demander la génération**.

    ![Demander la génération](img/dep-bulletins-generer.png)

3. Un message confirme que la demande a été enregistrée. Vous recevrez un mail dès que la liasse sera disponible.

    ![Message de confirmation](img/dep-bulletins-confirmation.png)

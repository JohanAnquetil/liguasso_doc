# Générer les bulletins de réadhésion d'une association

!!! chemin "Accès"
    Dans le menu, cliquez sur **Affiliation**, puis sur **Gestion des bulletins de ré-adhésion**.

Cet écran demande la génération de la **liasse des bulletins de réadhésion** d'une association. La liasse est produite par Ligu'asso, puis mise à votre disposition par mail.

![Menu Gestion des bulletins](img/dep-bulletins-menu.png)

## Demander la liasse

1. Dans le bloc **Recherche**, saisissez le nom de l'association dans le champ **Association**, sélectionnez-la, puis cliquez sur **Rechercher**.

    ![Page des bulletins](img/dep-bulletins-page.png)

2. Dans la colonne **Actions** des **Résultats**, cliquez sur l'icône **Demander la génération**.

    ![Demander la génération](img/dep-bulletins-generer.png)

3. Un message confirme que la demande est enregistrée.

    ![Message de confirmation](img/dep-bulletins-confirmation.png)

Vous recevez un mail dès que la liasse est disponible.

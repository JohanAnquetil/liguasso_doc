# Valider des adhésions en masse

Si vous avez un nombre important d'adhésions à valider, vous pouvez les traiter en une fois plutôt qu'une par une.

1. Cliquez sur le menu **Adhésion** puis **Lots**.
2. Cliquez sur **Nouveau lot**, à droite de l'écran.

    ![Nouveau lot](img/dep-lot-nouveau.png)

3. Sélectionnez la **saison** (obligatoire). Vous pouvez restreindre à une association (facultatif), puis cliquez sur **Rechercher**. La recherche avancée permet d'affiner davantage.

    ![Recherche](img/dep-volume-recherche.png)

4. Les adhésions en attente s'affichent. Cochez les lignes voulues, ou cliquez sur **Tout sélectionner** puis augmentez le nombre de lignes par page.

    ![Sélection](img/dep-volume-selection.png)

    !!! warning "Limitation connue — septembre 2026"
        Seule la première page est comptabilisée dans le lot, soit **100 adhésions au maximum**. Créez plusieurs lots en attendant la correction.

5. Cliquez sur **Enregistrer**, puis sur l'icône ✓ dans la colonne **Actions**.

    ![Valider le lot](img/dep-volume-valider.png)

6. Indiquez la date d'homologation si le champ apparaît, puis **Valider**.

    ![Date d'homologation](img/dep-volume-homologation.png)

Les adhésions sélectionnées passent au statut **validée** et disparaissent de la liste des dossiers à traiter. Les adhérent.e.s ayant renseigné leur mail reçoivent leur licence.

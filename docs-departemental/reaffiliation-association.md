# Réaffilier une association

1. Dans le menu, survolez **Affiliation** puis cliquez sur **Gérer les affiliations**.
2. Filtrez par état en sélectionnant **à réaffilier**, ou recherchez l'association par nom ou numéro d'affiliation, puis cliquez sur **Rechercher**.

    ![Recherche des associations à réaffilier](img/dep-reaffilier-recherche.png)

3. Les associations affiliées pour la saison en cours s'affichent, avec leur statut pour la saison suivante. Cliquez sur le bouton de réaffiliation, colonne **Actions**.

    ![Résultats et statuts](img/dep-reaffilier-resultats.png)

## Le parcours prérempli

Le bouton ouvre le parcours d'affiliation **prérempli** pour la nouvelle saison. Saisissez uniquement la nouvelle date d'affiliation, puis cliquez sur **Étape suivante**.

![Date d'affiliation](img/dep-reaffilier-date.png)

Vérifiez les informations préremplies dans chaque onglet et modifiez-les si besoin.

!!! note "Onglet UFOLEP"
    Les données de l'onglet UFOLEP doivent être remises à jour chaque saison, afin d'actualiser le type d'affiliation choisi et la gestion des documents d'adhésion. Elles sont obligatoires pour poursuivre.

## Valider

Le résumé permet une dernière vérification. Cliquez sur **Valider l'affiliation**.

![Résumé](img/dep-reaffilier-resume.png)

Vérifiez les dates d'affiliation, modifiez-les si besoin, puis cliquez sur **Valider**.

![Validation des dates](img/dep-reaffilier-valider.png)

Vous revenez automatiquement sur **Gérer les affiliations**, où vous pouvez filtrer par **État** pour voir les associations réaffiliées.

![Liste des réaffiliées](img/dep-reaffilier-liste.png)

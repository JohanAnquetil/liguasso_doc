# Réaffilier une association

!!! chemin "Accès"
    Dans le menu, cliquez sur **Affiliation**, puis sur **Gérer les affiliations**.

La fédération peut réaffilier elle-même une association pour la nouvelle saison. Le parcours est **prérempli** avec les informations de la saison précédente : il suffit de les vérifier.

## Trouver l'association à réaffilier

1. Dans le bloc **Recherche**, choisissez l'**État** **A réaffilier**, ou recherchez l'association par nom ou numéro d'affiliation.
2. Cliquez sur **Rechercher**.

    ![Recherche des associations à réaffilier](img/dep-reaffilier-recherche.png)

3. Les associations affiliées pour la saison en cours s'affichent, avec leur état pour la saison suivante. Dans la colonne **Actions**, cliquez sur l'icône de réaffiliation.

    ![Résultats et statuts](img/dep-reaffilier-resultats.png)

## Vérifier le parcours prérempli

1. Saisissez la nouvelle **date d'affiliation**, puis cliquez sur **Étape suivante**.

    ![Date d'affiliation](img/dep-reaffilier-date.png)

2. Vérifiez les informations de chaque onglet et corrigez ce qui a changé.

!!! note "Onglet UFOLEP"
    Les informations de l'onglet **UFOLEP** doivent être mises à jour **chaque saison** : type d'affiliation choisi et gestion des documents d'adhésion. Elles sont obligatoires pour continuer.

## Valider la réaffiliation

1. Sur le résumé, faites une dernière vérification et cliquez sur **Valider l'affiliation**.

    ![Résumé](img/dep-reaffilier-resume.png)

2. Vérifiez les dates d'affiliation, corrigez-les si besoin, puis cliquez sur **Valider**.

    ![Validation des dates](img/dep-reaffilier-valider.png)

Vous revenez sur **Gérer les affiliations**. Filtrez par **État** pour voir les associations réaffiliées.

![Liste des réaffiliées](img/dep-reaffilier-liste.png)

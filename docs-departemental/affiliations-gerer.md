# Gérer les affiliations

!!! chemin "Accès"
    Dans le menu, cliquez sur **Affiliation**, puis sur **Gérer les affiliations**.

L'écran **Gérer les affiliations** donne une vue d'ensemble des associations de votre département. C'est ici que vous **validez** les affiliations transmises par les associations, et que vous créez, modifiez ou réaffiliez une association.

![Menu Affiliation](img/dep-affiliations-menu.png)

## Rechercher une association

1. Dans le bloc **Recherche**, saisissez le nom ou le numéro de l'**Association**.
2. Filtrez si besoin par **État** (voir la liste plus bas).
3. Cliquez sur **Rechercher**. **Recherche Avancée** propose d'autres critères.

![Gérer les affiliations](img/dep-affiliations-gerer.png)

## Agir sur une affiliation

Les icônes de la colonne **Actions** permettent de **visualiser** l'affiliation, la **modifier**, la **valider**, **annuler les modifications** en cours, **imprimer le bulletin** et consulter son **historique**.

Pour créer une affiliation, cliquez sur **Nouvelle affiliation**, en haut à droite. → [Créer une affiliation](affiliations-creer.md)

![Bouton Nouvelle affiliation](img/dep-affiliation-bouton.png)

## Les états d'une affiliation

Le filtre **État** propose :

| État | Signification |
|---|---|
| **A réaffilier** | Association affiliée la saison précédente, pas encore réaffiliée |
| **Affiliation en cours** | Parcours d'affiliation commencé, pas encore terminé |
| **Modification en cours** | Modification de l'affiliation commencée, pas encore terminée |
| **Transmise non imprimée** | Affiliation transmise, bulletin pas encore imprimé |
| **A valider doc papier** / **doc scanné** / **doc électro** | Affiliation transmise avec un bulletin papier, scanné ou signé électroniquement, à valider par la fédération |
| **Toute à valider** | Toutes les affiliations à valider, quel que soit le mode de transmission |
| **Validée** | Affiliation validée pour la saison |
| **Dévalidée** / **Suspendue** | Validation annulée, ou affiliation suspendue |

## Une affiliation n'apparaît pas ?

- **Elle vient d'être validée** : elle peut mettre quelques secondes à s'afficher. Actualisez la page.
- **Le parcours n'a pas été finalisé** : voir [Corriger une affiliation](affiliations-corriger.md).
- **Le siège de l'association n'est pas dans votre département** : elle n'apparaît pas automatiquement chez vous. Aucune dérogation n'est possible pour les affiliations USEP et socioculturelles.

# Gérer les affiliations

!!! chemin "Accès"
    **Affiliation** › **Gérer les affiliations**

Dans le menu, survolez **Affiliation** puis cliquez sur **Gérer les affiliations**.

![Menu Affiliation](img/dep-affiliations-menu.png)

Cet écran donne une vue globale sur les associations déjà affiliées. La rubrique **Recherche** permet de les retrouver ; la colonne **Actions** permet de les visualiser, les modifier, les **valider**, annuler les modifications et consulter leur historique.

![Gérer les affiliations](img/dep-affiliations-gerer.png)

Pour créer une nouvelle affiliation, cliquez sur **Nouvelle affiliation**, en haut à droite.

![Bouton Nouvelle affiliation](img/dep-affiliation-bouton.png)

!!! tip "Une affiliation n'apparaît pas ?"
    Les affiliations tout juste validées peuvent mettre quelques secondes à s'afficher : actualisez la page. Par ailleurs, si le siège de l'association n'est pas domicilié dans le département de votre fédération, elle n'apparaîtra pas automatiquement. Aucune dérogation n'est possible pour les affiliations USEP et socioculturelles.

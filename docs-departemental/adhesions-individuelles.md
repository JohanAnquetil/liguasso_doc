# Gérer les adhésions individuelles

!!! chemin "Accès"
    Dans le menu, cliquez sur **Adhésion**, puis sur **Adhésions individuelles**.

Une **adhésion individuelle** est une adhésion directe à la fédération, sans passer par une association. L'écran **Adhésions à titre individuel** permet de suivre les demandes et d'en enregistrer de nouvelles.

![Menu Adhésions individuelles](img/dep-individuelles-menu.png)

## Suivre les demandes

1. Dans le bloc **Recherche**, choisissez la **Saison**. Le **Département** est déjà rempli.
2. Cochez **Validées**, **A traiter**, ou les deux.
3. Cliquez sur **Rechercher**. Les demandes s'affichent dans **Résultats**.

![Liste des demandes](img/dep-individuelles-liste.png)

## Enregistrer une adhésion individuelle

1. Cliquez sur **Nouvelle Adhésion Individuelle**.
2. Renseignez si besoin le **N° demande** et sa date (**En date du**).
3. Renseignez l'identité : **Femme** ou **Homme**, **Nom**, **Prénom**, **Date de naissance**.
4. Renseignez les coordonnées : **Adresse 1**, **Code Postal**, **Ville**, **Email**, **Téléphone** (obligatoires). Si la personne est déjà adhérente, indiquez son **N° Adhérent**.
5. Vérifiez le **Département de rattachement**.
6. Cochez ses centres d'intérêt parmi : culture et communication, Europe, solidarité internationale, plein air et sports, droits aux vacances, éducation, formation, lutte contre les discriminations, rendez-vous citoyens, environnement et développement durable, laïcité, solidarité et territoires.
7. Indiquez le mode de règlement : **CB**, **Chèque** ou **Espèce**.
8. Cliquez sur **Enregistrer**.

![Nouvelle adhésion individuelle](img/dep-individuelles-nouvelle.png)
